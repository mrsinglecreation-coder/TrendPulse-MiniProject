# TrendPulse – Part 1

## Project Overview
TrendPulse is a YouTube Trending Videos Data Analysis project using Python.

## Technologies
- Python
- Lists, Dictionaries, Tuples and Sets
- Loops and Functions
- Data Cleaning
- Google Colab

## Datasets
- US YouTube Trending Videos
- GB YouTube Trending Videos
- India YouTube Trending Videos
- Video Category Information

## Part 1 Objectives
- Load datasets
- Clean and convert data types
- Work with Python data structures
- Apply loops, conditions and functions
- Classify videos using Python

## Dataset Source
YouTube Trending Videos dataset.
