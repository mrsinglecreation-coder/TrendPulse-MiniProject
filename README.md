TrendPulse – YouTube Trending Videos Analysis

Project Overview

TrendPulse is a Python-based data analysis project that explores trending YouTube videos across different countries.

The project focuses on data cleaning, Python programming, data structures, data analysis, and extracting meaningful insights from real-world datasets.

Project Parts

Part 1 – Python Foundations & Data Structures

- Python fundamentals
- Lists, tuples, sets, and dictionaries
- Data cleaning and type conversion
- Loops and functions
- YouTube video classification

Project folder: "part1_python_foundations/"

Technologies Used

- Python
- Pandas
- Google Colab
- Git and GitHub

Dataset

YouTube Trending Video Statistics dataset covering:

- United States (US)
- Great Britain (GB)
- India (IN)
